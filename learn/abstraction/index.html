Abstraction

BlueSystemCommonCard 16/70

A representation that keeps some features and leaves others out.

In real life

A subway map leaves out streets and buildings so you can focus on the stops. AI models simplify the world in the same way.

Try it (2 minutes)

Draw a map from your home to school using only five things. What did you leave out, and why?

Talk about it

If you drew a map of your school, what would you leave out?

In the game
