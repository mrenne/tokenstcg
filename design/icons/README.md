# Card art

One image per card. The v2 card generator (`design/frame-v2/build-card.js`) picks each one up by file name.

- **Size:** 1396 x 516 px (the art window at 2x print resolution). Other sizes of about the same shape work; the frame trims evenly from the edges.
- **Format:** PNG or JPG, sRGB, with no transparency.
- **Keep clear:** the bottom center (about x 430-970, y 300-516) sits under the CAP/TRU diamonds or the type badge.
- **File name:** exactly as listed below, plus `.png` or `.jpg`. Names follow the card name, not its number, so they stay the same when cards are added or reordered.

To rebuild every card after adding art: `node design/frame-v2/build-card.js --all`
