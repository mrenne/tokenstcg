Model Card

WhiteToolCommonCard 50/70

A document describing an AI model's training, performance, and limitations — like a nutrition label.

In real life

A model card is like a nutrition label for AI. It tells what the model is for, what data it learned from, and where it doesn't work well.

Try it (2 minutes)

Write a mini "model card" for yourself as a helper: what you're good at, what you're not, and what you shouldn't be asked to do.
