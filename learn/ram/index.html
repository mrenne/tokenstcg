RAM

BlackToolCommonCard 44/70

A computer's short-term memory, holding the data a program is working with right now.

In real life

RAM holds whatever the computer is working on right now, and it's wiped when the power goes off.

Try it (2 minutes)

Remember a 7-digit number for 30 seconds without writing it down. Your short-term memory is like RAM.

Talk about it
